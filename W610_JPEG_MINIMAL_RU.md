# W610 JPEG Test — отдельный тест с минимальными разрешениями

Это отдельный Android-модуль `:w610jpeg`, пакет `com.fersaiyan.cyanbridge.w610jpegtest`, имя **W610 JPEG Test**. Android 12 или новее; Samsung S23 подходит. Основной CyanBridge и предыдущий `.w610test` он не заменяет. Ветка основана на `e2aa1094001214c83ca26e3e466501f92a9f448c` со всеми исправлениями приёма JPEG.

## Что входит в приложение

Только BLE-подключение к W610, запрос фото, приём JPEG, просмотр, сохранение в `DCIM/CyanBridge W610` и экспорт собственного журнала через системный выбор файла. Модуль компилирует без изменений пять существующих файлов приёмника, SDK-адаптера, валидатора JPEG, MediaStore и координатора. Код и манифест основного `:app` остаются прежними.

Два Android-разрешения: `BLUETOOTH_SCAN` с `neverForLocation` и `BLUETOOTH_CONNECT`. AndroidX также добавляет собственное signature-разрешение для защиты внутренних динамических приёмников; это не доступ к данным пользователя.

Нет NotificationForwarderService, notification listener, accessibility, SMS, звонков, камеры телефона, микрофона, геолокации, оверлеев, доступа к чужим файлам, сети или фоновых служб. Разрешение `ANSWER_PHONE_CALLS`, которое вносит SDK очков, явно удаляется при слиянии манифеста. Android 10/11 намеренно не поддерживаются этим узким тестом, чтобы не требовать геолокацию для BLE-поиска.

Google документирует блокирование некоторых устанавливаемых из интернета приложений с notification listener и другими чувствительными возможностями: https://developers.google.com/android/play-protect/warning-dev-guidance . Это объясняет вероятный источник прежнего предупреждения, но точное решение Play Protect на конкретном S23 можно проверить только установкой. Изменение разрешений не является гарантией вердикта Google; отключать защиту для испытания не требуется и не предлагается.

## Установка и один тест

1. Скачайте новый APK **CyanBridge-W610-JPEG-Minimal.apk**, откройте через «Мои файлы» и установите **W610 JPEG Test**. Предыдущие APK и основной CyanBridge удалять не нужно. Это подписанная тестовым сертификатом сборка; она не является релизом основного приложения.
2. Принудительно остановите HeyCyan и оба других CyanBridge, чтобы они не занимали BLE. Включите очки. Откройте W610 JPEG Test, нажмите **Найти и подключить W610**, разрешите **Ближайшие устройства**, выберите свои очки в списке BLE и дождитесь сообщения о подключении.
3. Оставьте этот экран открытым. Наведите очки на узнаваемый предмет. Нажмите физическую кнопку AI/фото либо **Сделать фото на очках**. Ожидается **W610 JPEG OK**, изображение на экране и свежий снимок в Галерее, альбом **CyanBridge W610**. Повторите один раз с другим предметом.
4. После незавершённого приёма/таймаута нажмите **Отключить очки**, затем подключите снова. Это обязательная защита от поздних пакетов SDK без идентификатора транзакции. При уходе приложения с экрана BLE отключается; после возвращения подключите очки снова.
5. При неудаче нажмите **Сохранить журнал**, выберите файл через системное окно и передайте журнал одной попытки. Он содержит диагностику передачи и может содержать адреса устройства из SDK; проверьте его перед публичной публикацией.

Если Play Protect опять остановит установку, сохраните точный текст/скриншот и имя проверенного APK. На таком телефоне тест пока не выполнен. Следующий шаг — разбор предупреждения или официальная проверка/апелляция для нового файла, а не отключение защиты.

Для отката закройте/удалите только **W610 JPEG Test** и снова откройте основной CyanBridge или HeyCyan. Tasker, помощник по умолчанию и основная конфигурация не меняются. Передача в ChatGPT Live этим тестом не проверяется.

## Проверки сборки

```bash
cd android/CyanBridge
JAVA_HOME=/path/to/jdk17 ./gradlew --no-daemon --max-workers=2 \
  :w610jpeg:testDebugUnitTest :w610jpeg:lintDebug :w610jpeg:assembleDebug
```

Meta SDK и его секрет для этого модуля не нужны. Все 26 тестов прежнего приёмника запускаются и здесь. Для JPEG-тестов меняется только Robolectric API 29 → 32, соответствующий минимальному Android тестового APK; проверки содержимого остаются прежними. Дополнительно проверяются минимальный merged manifest, события `0x02/0x03` и однократное освобождение permit в промежутке до запуска receiver.

Workflow `W610 JPEG minimal` проверяет подпись, application ID, SHA-256, все unit-тесты модуля, lint и отсутствие изменений в `android/CyanBridge/app`. Конечный манифест извлекается из APK Android SDK `apkanalyzer` и независимо читается Python-анализатором; обе проверки используют строгий список разрешённых возможностей. Появление лишнего разрешения или службы останавливает сборку. В артефакты входят новый и предыдущий итоговые манифесты и отчёты о них.
