# CyanBridge W610: проверка получения фотографии

Этот APK проверяет только путь **W610 → CyanBridge**. Отправка фотографии в официальный ChatGPT Live в этом этапе не реализуется и не проверяется.

## Установка на Samsung S23

1. Сохраните APK на телефон, откройте его через «Мои файлы» и разрешите установку из этого источника, если Android попросит. Имя приложения — **CyanBridge W610 Test**, пакет — `com.fersaiyan.cyanbridge.w610test`. Основной CyanBridge удалять не нужно.
2. Если уже стоит старая **тестовая** версия с тем же пакетом и Android не даёт обновить её из-за другой подписи, удалите только **CyanBridge W610 Test**, затем установите этот APK. Настройки прежней тестовой версии будут удалены. Основной CyanBridge останется.
3. Перед проверкой принудительно остановите HeyCyan и основной CyanBridge в настройках Android. Подключите W610 в тестовом приложении; разрешите доступ к ближайшим устройствам и необходимые разрешения подключения. Не меняйте Tasker, AutoInput и приложение помощника по умолчанию.

**Условие:** эти шаги выполняются только после получения APK с успешной сборкой. На текущем этапе наличие APK подтверждается отдельным отчётом, а не этой инструкцией.

## Один короткий тест

1. Откройте тестовый CyanBridge, выберите HeyCyan/W610 и убедитесь, что показано подключение. Оставьте перехват AI включённым; выберите **Fast preview**. Подписка или ключ стороннего AI для этого теста не нужны.
2. Наведите очки на хорошо различимый предмет и используйте физическую кнопку AI-фото, которой получали событие photo-ready `0x02`. В тестовой версии ранее добавленный путь `0x03` также запускает камеру; голосовой маршрут основной версии не меняется. Для отдельного сравнения доступна кнопка приложения **Test Image AI description**.
3. Дождитесь сообщения **W610 JPEG OK**. Откройте «Галерею», альбом **CyanBridge W610**. Там должен быть свежий снимок именно текущего предмета. Повторите с другим предметом, дожидаясь завершения предыдущей попытки.
4. Если около 20 секунд нет завершения передачи, приложение освободит блокировку и попросит переподключить очки. Выключите и включите очки, дождитесь нового BLE-подключения и повторите один раз. Не держите одновременно запущенными оба CyanBridge и HeyCyan.

**Успех:** свежий узнаваемый JPEG в галерее и сообщение `W610_PREVIEW_OK` в журнале. Один только звук затвора, событие `0x02` или успешная компиляция успехом передачи не считаются.

## Журнал, если фотография не пришла

При подключённом ADB на компьютере:

```bash
adb logcat -c
adb logcat -v threadtime -s ImageQuestionTransfer ImageQuestion DeviceNotify GlassesSession GLASSES_LOG > w610-test.log
```

Нажмите кнопку очков один раз, дождитесь результата и остановите запись `Ctrl+C`. Перед передачей журнала проверьте его: SDK может выводить адреса Bluetooth и бинарные данные фотографии. Не публикуйте журнал в открытом issue без проверки.

В журнале нужны: photo-ready; `settleWaitMs`; `attempt=1/2`; `SDK=getPictureThumbnails`; `chunks`, `bytes`, `complete`; `jpegDecoded=true/false`; `W610_PREVIEW_OK` либо `reconnectRequired=true`. Путь исходного JPEG находится в той же строке успеха. Альбом использует MediaStore и не требует доступа к системной папке Android/data.

## Откат

Принудительно остановите или удалите только **CyanBridge W610 Test**, затем снова откройте основной CyanBridge либо HeyCyan и подключите очки. Исходные профили Tasker и основной пакет этот APK не заменяет. Снимки, сохранённые в галерее, можно удалить обычным способом.

## Сборка из исходников

Java 17+ (полный JDK), Android SDK 35/36, Build Tools 36.0.0, подмодуль Myvu. Данный исходный проект также требует доступ к Meta DAT SDK через `META_GITHUB_TOKEN` с правом чтения соответствующих GitHub Packages. Для использования уже собранного APK ключи Meta или AI вводить не нужно.

```bash
git submodule update --init --recursive
cd android/CyanBridge
JAVA_HOME=/path/to/jdk17 ./gradlew --no-daemon --max-workers=2 -PtestAbi=arm64-v8a \
  :app:testDebugUnitTest \
  --tests 'com.fersaiyan.cyanbridge.ai.image.BleThumbnailTransferTest' \
  --tests 'com.fersaiyan.cyanbridge.ai.image.ThumbnailJpegValidatorTest' \
  --tests 'com.fersaiyan.cyanbridge.glasses.GlassesSessionCoordinatorTest' \
  :app:assembleDebug
```

Переменную `META_GITHUB_TOKEN` задавайте через безопасные настройки среды/секреты Actions; не помещайте значение в исходники, письма или журналы. APK: `android/CyanBridge/app/build/outputs/apk/debug/app-debug.apk`. ARM64 подходит для S23.

## Технические ограничения

- Интеграция основана на `w610-thumbnail-fix` (`7c767ab83c9aacb7befec1bbe7006d1962d78d29`); из резервной `w610-local-backup-20261022` (`a9bee2b45b92f948cd1cb8b4103deb6f75b1d4e7`) перенесены идеи ограниченного повтора, отдельных файлов и владения permit до завершения всей операции. Исходные ветки сохраняются.
- SDK из `glasses_sdk_20250723_v01.aar` хранит thumbnail callback в `respMap[-3]`, сам запрашивает следующий чанк и не передаёт идентификатор транзакции. Удаляется только собственная запись этой операции; общий `cleanMap()` не вызывается.
- После завершённой, но невалидной картинки разрешён один повтор через 300 мс. После таймаута, отмены или ошибки при незавершённом SDK-запросе новый thumbnail разрешается только после реального BLE-переподключения: иначе поздний пакет старого запроса неотличим от нового. Общий permit освобождается в любом случае. Автоматически разрывать Bluetooth ради повтора приложение не будет.
- Проверяются SOI/EOI JPEG, размер, размеры кадра, MIME и реальное декодирование пикселей. Верхние пределы preview: 8 MiB и 4096×4096. Это не доказательство свежести кадра: её подтверждает проверка разных предметов на реальных очках.
- Прошивка W610, BLE на S23 и стабильность аудио требуют физической проверки. Общая история и передача в ChatGPT Live относятся к следующему этапу.
